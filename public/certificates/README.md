# Certificates

Drop your certificate files (PDF, PNG or JPG) in this folder. Sub-folders are fine.

Link one to its entry in `src/content/education.ts` with a path relative to this folder:

    { title: 'ISTQB ...', ..., certificate: 'ISTQB - Foundation/Brightest2022015680.pdf' }

Entries with a `certificate` get a "View certificate" link on the Education page.
