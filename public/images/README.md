# Images

Drop images for the website (WebP, JPG, PNG or SVG) in this folder. Sub-folders are fine.

Reference one with a path relative to this folder. For example, the home page photo is set in
`src/content/profile.ts`:

    photo: 'profile.jpg'

Tips: prefer WebP, resize to about twice the displayed size (900-1400 px wide is plenty) and keep files under ~300 KB for fast loading.
