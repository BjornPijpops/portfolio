# Images

Drop images for the website (JPG, PNG, WebP or SVG) in this folder. Sub-folders are fine.

Reference one with a path relative to this folder. For example, the home page photo is set in
`src/content/profile.ts`:

    photo: 'profile.jpg'

Tips: use a roughly square photo (at least 600x600 px) and keep files under ~300 KB for fast loading.
